## About

Hi, I'm **Yash Waje** — an AI and Machine Learning student interested in building useful software and learning through hands-on projects.

My repositories explore machine-learning applications, resume and job-description analysis, citizen-assistance software, and event-management interfaces. I focus on making projects understandable through clear documentation, practical workflows, and continued iteration.

- Building and learning with **Python, machine learning, and web technologies**
- Exploring **NLP, data analysis, and API-backed applications**
- Improving project structure, documentation, and software development practices

A resume-to-job-description analysis tool. It extracts text from PDF resumes and uses TF-IDF and cosine similarity to surface matching skills, skill gaps, keywords, and recommendations.
